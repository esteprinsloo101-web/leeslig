# LeesLig — Afrikaans Leespraktyk Pack (sellable)

**Brand:** LeesLig (faceless)  
**Price target:** R99–R129 (listing default **R99**)  
**Audience:** SA parents/caregivers of Grades 1–7 who want short Afrikaans reading practice at home.

## What’s inside
- `DISCLAIMER.md` — legal fence (required)
- `SETUP.md` — how to unpack & use
- `parent-guide/Parent_Guide.md` — short sessions, ADHD-friendly *design* tips (not treatment)

- `worksheets/` — printable HTML practice sheets (Gr 1–3 fuller; Gr 4–7 DEMO stubs) + answer notes
