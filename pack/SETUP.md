# LeesLig pack — SETUP

1. Unzip `LeesLig_Afrikaans_Reading_Practice_Pack.zip`.
2. Open `parent-guide/Parent_Guide.md` first (5 minutes).
3. Print worksheets from `worksheets/` (or open the HTML in a browser and Print → PDF/paper).
4. Use with the free web app (`index.html`) for short 3–8 minute sessions.
5. Parent mode in the web app gates settings (simple sum).

**Reminder:** enrichment only · not CAPS/DBE · not ADHD treatment · parent/guardian supervised.
